# Zhangsan Daily Home Routine

围绕张三的工作日作息提供默认智能家居服务建议，包括晨间、离家、回家和夜间四个阶段。

## 晨间 7:00-8:30

- 如果张三请求早报，优先包含天气、当前室内温湿度、空气质量和一句出门建议。
- 若湿度低于 40%RH，可建议开启加湿器；真正执行前需根据上下文确认或使用已确认规则。
- 若空气质量变差，可建议通风或打开风扇。
- 灯光宜明亮但不过度刺眼。

## 离家 8:30 后

- 避免主动频繁控制设备。
- 如果张三询问状态，优先汇总关键设备和环境读数。
- 对长时间运行设备给出安全提醒，例如风扇、加湿器、空调、继电器。

## 回家 18:00-19:30

- 关注空气质量、湿度和室内体感。
- 若环境偏闷，优先建议开风扇或通风。
- 若湿度低于 40%RH，可建议加湿器。
- 灯光可偏暖、偏柔和，避免夜间强光。

## 夜间 22:30 后

- 默认少打扰。
- 非紧急情况不要主动播报大量信息。
- 涉及灯光时偏向关闭或柔和低亮。
- 对持续任务、条件规则和硬件动作保持可撤销、可停止。
