## 10. 资料可信度优先级

遇到冲突时按以下顺序判断：

1. 当前分支实际编译源码与 `main/CMakeLists.txt`。
2. 当前配置文件、Schema 和脚本实现。
3. 当前运行日志与赛前实测。
4. README 和专题文档。
5. 累积历史知识库、开发计划、状态快照。

旧文档中仍可能包含已删除的 voice、Gateway 或 OTA planning，也可能保留旧角色模型。答辩材料已经按当前源码修正，但比赛前若 commit 变化，应重新核验本地图。
